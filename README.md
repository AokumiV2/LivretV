# Livret C Frontend Demo

Frontend-only Next.js demo for Livret C with localStorage mock data.

## Run

```bash
npm i
npm run dev
```

This is a frontend-only demo using localStorage mock data.

## Features

- Login simulation + Smart Account creation
- Marketplace farms/baskets/secondary market
- Portfolio with PnL, claimable rewards, transactions, CSV export
- Rewards claim center with payout proofs
- Farms map + farm details (KPI, production, incidents, data room)
- Settings + admin simulation panel
